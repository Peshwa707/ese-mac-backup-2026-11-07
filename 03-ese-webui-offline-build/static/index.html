7. Screen & adjudicate

No run selected

Run the offline engine's cached screening against the run's locked protocol; it produces one include/exclude/abstain decision per record. Human adjudication defaults to off: an abstained record never blocks the screen stage unless you explicitly turn adjudication on below. When adjudication is on, every unresolved abstention opens a blocking queue entry that must be resolved (include/exclude) before the screen stage reads complete. Re-running screening always invalidates any earlier adjudications, and flipping the toggle re-evaluates any already-screened run immediately, including retroactively.

11. Package & replay

No run selected

Bundle a fully-screened run's stage artifacts (frozen import, dedup, lock, and screen) into a single package artifact, then replay that package and compare the reproduced artifacts against the originals, byte for byte. Packaging requires screening to be complete (and unblocked); replaying requires a package to be complete. Re-running an earlier stage invalidates any package/replay artifacts and stage completions built on top of it, exactly like the dedup/lock/screen cascade above. A replay that runs successfully but reproduces different bytes reads mismatched, not complete, and the mismatching output is kept on disk for audit instead of being discarded.
