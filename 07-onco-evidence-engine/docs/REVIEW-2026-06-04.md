# Code Review — Phases 0–3 vertical slice (2026-06-04)

A 5-agent parallel review (correctness, PHI/security, anti-hallucination integrity,
architecture/boundary, tests) audited the shipped implementation. This records what
was **fixed in this pass** and what is **deferred to Phase 5 (hardening)**, so nothing
is silently dropped.

## Fixed in this pass

### Safety — PHI de-identification (`core/grounding/deid.py`)
- Added detection for untitled names (`Patient: Jane Doe`), ALL-CAPS names (`JOHN SMITH`),
  ISO-8601 dates (`YYYY-MM-DD`), prose dates (`January 5, 1962`), hyphenated ages
  (`95-year-old`), more EHR ID labels (`Patient ID`, `Chart #`, `Record #`), case-insensitive
  addresses, and space-separated / labeled-undelimited SSNs.
- The clinical ALL-CAPS allowlist (NSCLC, EGFR, …) was **moved out of `core/` into the
  oncology vertical** (`schema.yaml: deid.caps_allowlist`); the scrubber now takes it as a
  parameter from `VerticalConfig.deid_caps_allowlist`. Core stays domain-neutral.
- Tests: parametrized PHI coverage, a partial-leak second-pass test, clinical-content survival.

### Anti-hallucination integrity
- **Manuscript path** no longer receives the raw patient case; added a post-generation
  inline-citation audit (`synthesize._audit_manuscript`) flagging ungrounded claim sentences;
  flags are routed into the provenance trail (`manuscript_claim_ungrounded`).
- **Synthesis** prompt no longer includes the raw structured case (removes a second,
  unguarded knowledge source).
- **Quote-anchoring is now a GATE** (`verify.apply_cite_or_omit`): empty/too-short/unanchored
  quote → finding dropped (`reason=quote_not_anchored`), with `conflicts_with` remap.
- **Claim-checker fails closed**: parse/LLM exceptions drop the finding
  (`reason=claim_check_failed`) instead of aborting the job.
- Tests added: `test_claim_checker.py`, `verify_citations` coverage, `test_pipeline_offline.py`.

### Architecture / boundary
- Template filenames, the guidelines `ref_key`/`default_title`, and the de-id allowlist all
  moved to vertical config; `core/` no longer hardcodes oncology strings.
- `load_vertical` lru_cache split fixed (resolve name → cache on resolved string).
- Boundary test strengthened (denylist now includes `pdq_summaries`, `care_report.html`,
  `decision_support.html`, `care-guideline`, more drug names) and **passes**.

### Correctness / infra
- `connectors/base.py`: 4xx no longer retried with 15s backoff (only 429/5xx + transport errors).
- `retrieval.py`: `asyncio.gather(return_exceptions=True)` so one connector can't cancel siblings.
- `api/app.py`: catch-all logs server-side, returns generic error (no message leak).
- `models.py`: `Citation.url` validator rejects non-http(s) schemes (blocks `javascript:` XSS).
- `pyproject.toml`: `pytest-cov` + coverage reporting; `.github/workflows/ci.yml` added.
- Connector + API contract tests expanded (CT/openFDA/PDQ verify + degradation, POST /analyze,
  409/404/503/422 paths).

Result: **75 passed, 1 skipped, ~80% coverage.**

## Phase 5 (hardening) — DONE 2026-06-04 (104 passed, 1 skipped)

- ✅ **Auth**: bearer-token via `ONCO_API_TOKEN` — 401 when set & missing/wrong, dev-allow-with-warning when unset.
- ✅ **Supply chain**: hash-pinned `requirements.lock` (incl. dev extras); CI installs from it.
- ✅ **PDF sandbox**: `--no-sandbox` dropped by default; opt-in via `ONCO_CHROME_NO_SANDBOX=1`.
- ✅ **JOBS store**: TTL eviction (`ONCO_JOB_TTL_SECONDS`, default 3600); provenance dir 0700 / files 0600.
- ✅ **SSRF**: PDQ/guidelines connector validates scheme (https) + host allowlist before any fetch.
- ✅ **Prompt-injection**: case text + snippets wrapped in `<case>/<snippets>/<findings>/<sources>`
  delimiters with "data, not instructions" clause in every system prompt.
- ✅ **Verification depth**: openFDA verify now matches drug name to citation title; PDQ verify
  requires snippet content present (falls back to liveness only when no snippet/title).
- ✅ **LLM-prompt externalization** (H1/H2): all system prompts moved to `verticals/oncology/schema.yaml`;
  core keeps neutral fallbacks only.
- ✅ **`default_connectors()`** (C4): connector SELECTION now from vertical config
  (`connectors_for_vertical`); core keeps only the class registry.
- ✅ **Conflict context** (AH F8): dropped findings that contested a survivor are logged to
  provenance (`conflict_context_lost`).

### Still intentionally deferred
- **Model field names** (`decision_support`, `manuscript`): kept as the generic contract's
  lingua franca — renaming is high-churn, low-value. Documented, not changed.
- **Live end-to-end run**: requires `ANTHROPIC_API_KEY` + network; not yet exercised.
- **Production deploy concerns** beyond the above (rate limiting, real secrets manager, container
  isolation for Chrome) — when/if this is deployed.
