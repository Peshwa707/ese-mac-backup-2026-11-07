# Neurodevelopmental environmental-mismatch review inputs

This directory contains the frozen, non-identifying inputs for a seven-module
rapid systematic evidence review of the Adaptive-Constraint and
Environmental-Mismatch Model.

The source case narrative is intentionally not copied into the repository.
Literature selection uses only the generic claims in `claim_ledger.csv`.
Individual applicability is assessed only in the downstream psychiatrist-facing
draft.

The modules are:

1. A — developmental persistence and compensation;
2. B — ADHD/ASD/DCD overlap and social functioning;
3. C — motivation, person-environment fit, and proposed strengths;
4. D — external cognitive scaffolding;
5. E1 — sleep and circadian modifiers;
6. E2 — mood, cannabis, stimulant, and nicotine modifiers;
7. F — daydreaming, rejection, anxiety, and emotional burden.

Every module is configured as a rapid review and narrative synthesis. No
cross-construct meta-analysis is prespecified.
